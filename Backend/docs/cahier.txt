Cahier des Charges - Blog "Mahdia Blue and Green"
1. PRÉSENTATION DU PROJET
1.1 Contexte et Vision
Mahdia Blue and Green est une initiative stratégique visant à positionner Mahdia comme hub régional des économies bleue, verte et circulaire. Le projet s'inscrit dans une démarche de développement durable et d'entrepreneuriat local, avec un objectif ambitieux : accompagner 50 porteurs de projets pour créer 10 entreprises viables.
Budget alloué : 7 810 DT HT
Porteur du projet : OIT Mahdia
Public cible : Entrepreneurs, étudiants, acteurs locaux de l'économie durable
1.2 Objectifs Stratégiques du Blog
Objectifs Marketing
•	Générer 5 000+ visiteurs uniques dans les 6 premiers mois
•	Atteindre un taux d'engagement de 15% (commentaires, partages, inscriptions)
•	Convertir 10% des visiteurs en participants aux ateliers
•	Positionner le site dans le top 3 Google pour les requêtes locales clés
Objectifs Communication
•	Créer une vitrine digitale professionnelle et inspirante
•	Diffuser du contenu éducatif sur les économies durables
•	Valoriser les success stories locales et internationales
•	Faciliter la mise en réseau des acteurs de l'écosystème
Objectifs Techniques
•	Assurer un temps de chargement < 2 secondes
•	Garantir une accessibilité WCAG 2.1 AA
•	Atteindre un score Google PageSpeed > 90/100
•	Optimiser pour le SEO local et mobile-first

3. SPÉCIFICATIONS TECHNIQUES
3.1 Stack Technologique Recommandée
CMS : WordPress 6.4+
•	Justification : Gratuit, extensible, SEO-friendly, large communauté
Thème : Développement sur-mesure ou thème premium adapté
•	Recommandation : GeneratePress Premium ou Kadence (légères, SEO-optimisées)
•	Alternative : Thème custom basé sur Underscores
Plugins Essentiels :
SEO & Performance :
•	Rank Math SEO ou Yoast SEO Premium
•	WP Rocket (cache et optimisation)
•	ShortPixel (compression images)
•	WP-Optimize (nettoyage BDD)
Fonctionnalités :
•	Advanced Custom Fields PRO (champs personnalisés)
•	WPForms ou Contact Form 7 (formulaires)
•	The Events Calendar (événements)
•	MailPoet ou Newsletter (emailing)
 
Sécurité :
•	Wordfence Security
•	UpdraftPlus (backups)
Multimédia :
•	Smush ou Imagify (optimisation images)
•	WP Video Lightbox (vidéos)
3.2 Hébergement et Infrastructure
Recommandations Tunisie :
1.	OVH France (datacenter proche, support français)
2.	PlanetHoster (hébergement vert, support francophone)
3.	Alternative locale : TopNet Business ou GlobalNet
Spécifications minimales :
•	PHP 8.0+
•	MySQL 5.7+ ou MariaDB 10.3+
•	SSL/TLS (Let's Encrypt gratuit)
•	Minimum 2 Go RAM
•	SSD storage
•	CDN recommandé (Cloudflare gratuit)
3.3 Performance et Optimisation
Objectifs mesurables :
•	Google PageSpeed Desktop : > 90/100
•	Google PageSpeed Mobile : > 85/100
•	Temps de chargement : < 2 secondes (3G)
•	Core Web Vitals : tous au vert
•	GTmetrix Grade : A
Techniques d'optimisation :
•	Lazy loading images et vidéos
•	Minification CSS/JS
•	Compression GZIP/Brotli
•	Cache navigateur (1 an pour assets statiques)
•	Critical CSS inline
•	Defer/Async JavaScript
•	Sprites CSS pour icônes
•	WebP pour images (avec fallback)
•	Font display: swap pour polices
