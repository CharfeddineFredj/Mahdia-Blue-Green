1. PROJECT OVERVIEW
================================================================================

Name: Mahdia Blue & Green
Purpose: A full-stack web application for promoting sustainable blue, green, 
         and circular economy in Mahdia, Tunisia.

Repository: https://github.com/zied1fatnassi/mahdia_bg

This platform serves as an informational and community hub for sustainable 
economic initiatives in the Mahdia region, featuring:
- Articles and blog posts about sustainability
- Event management and registration
- Questionnaires for community engagement
- User authentication with OAuth and 2FA
- Admin dashboard for content moderation

8. AUTHENTICATION & SECURITY
================================================================================

AUTHENTICATION METHODS:
-----------------------
1. Local Authentication (email/password)
   - Passwords hashed with bcryptjs (10 salt rounds)
   - JWT tokens for session management
   - Protected with 2FA when enabled

2. Google OAuth 2.0
   - Uses passport-google-oauth20
   - Automatic account creation for new users
   - Account linking for existing users by email

3. Microsoft OAuth
   - Uses passport-microsoft (Azure AD)
   - Same linking behavior as Google

TWO-FACTOR AUTHENTICATION:
--------------------------
- Implementation: TOTP (RFC 6238) with speakeasy
- QR Code generation with qrcode package
- 5 backup codes (SHA-256 hashed, one-time use)
- 30-second token window
- Compatible apps: Google Authenticator, Microsoft Authenticator, Authy, 1Password

SECURITY MEASURES:
------------------
- Helmet.js for HTTP headers security
- Rate limiting (100 req/15min)
- CORS with credentials
- XSS protection
- MongoDB query sanitization
- Password fields excluded from queries (select: false)
- 2FA secrets encrypted and hidden
